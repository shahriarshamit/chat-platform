# Chat Platform

**Version:** 0.1.0

A microservice-based chat platform built with Laravel.

## Technology Stack

- PHP 8.4
- Laravel 12
- MySQL
- JWT Authentication
- Redis (Planned)
- WebSockets (Planned)

## Services

### Auth Service

Responsibilities:

- User registration
- User login and logout
- JWT authentication
- User profile

### Chat Service

Responsibilities:

- Conversation management
- Messaging APIs
- Message history
- Real-time messaging (Planned)
